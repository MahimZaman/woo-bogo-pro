# Woo B.O.G.O Pro

Applies per-product buy-one-get-one rules in the WooCommerce cart.

## Installation

1. Place this directory at `wp-content/plugins/woo-bogo-pro/`.
2. Activate WooCommerce, then activate **Woo B.O.G.O Pro**.

## Usage

Edit a product and configure its offer in the product data panel. Add the qualifying quantity to a cart and verify that the configured free product appears.
